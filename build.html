Import account — Riot token

Paste your Riot access token (a JWT starting with eyJ…). You can also paste the full opt_in redirect URL — but copy it immediately, the #access_token=… part is stripped from the address bar within seconds — or the JSON from the local client's entitlements endpoint; the token (and entitlement) are picked out automatically. Paste just the access token — CardForge fetches the entitlements token for you automatically. Add one manually below only if auto-fetch fails.

From a single paste CardForge imports level, rank, balances, your equipped player card and buddies, plus your owned skins, variants, buddies and cards, and unlocks an “Owned” filter in the skin, buddy and player-card pickers.

Tokens expire in ~1h, are sent only to the riot-import edge function over HTTPS, and are never stored or published.
