The tier toolbar is behind the card.
Here is the fix.

On staging today the entire tier filter — presets, chips, cap, Apply, Reset — is painted underneath the opaque card stage. I proved it with document.elementFromPoint() and with a screenshot: not one of its 14 controls is reachable. Toggle Outline layers and press Run hit test to reproduce the proof, then switch to PROPOSED to see the same controls working.

Root cause. .tierbar is a static in-flow block. #stage is position:fixed; inset:var(--tbh) 0 0 0 with an opaque background, and --tbh is measured from the topbar alone. Positioned elements paint after in-flow blocks, so the stage covers the toolbar's whole band. Its hard-coded margin:64px cannot escape a fixed sibling.
Fix. One measured chrome stack. The filter row lives inside the sticky chrome, --chrome-h is the measured height of that whole stack, and the stage starts below it. Nothing in the filter row can be occluded because it is inside the element being measured. Rows collapse on demand so the chrome costs 52 px by default.
