QUICK WINS

5 items · one line each · zero risk

Five fixes that are each a single line or selector, all verified in the audits, all independent of everything below. I would fold these into the first commit regardless of what else you approve.

Why bundle them: each is too small to justify its own review cycle, but together they kill a layout mismatch (Catalog renders differently in the editor than for the buyer), an export that is not what the seller previewed, placeholder text that stays on screen looking like real data on a failed load, a dead 60% of the featured tile, and an inconsistent robots policy.

The tab title, too — document.title is never set per listing, so ten open listings are ten identical tabs.

The honest constraint: crawlers do not run JavaScript, so og: tags must exist in the served HTML. Two moving parts: a Supabase Storage bucket for the PNG at publish, and a ~20-line Netlify Edge Function to inject per-listing tags. If you would rather skip the edge function, the interim is one static brand image plus the per-listing title — still beats a bare URL.
